# bochaesporte

# 🔴🔵 Site do Mundo da Bocha

Projeto de um site sobre a **Bocha**, contendo explicação sobre o esporte, regras básicas e um marcador de pontos interativo para você usar durante partidas de bocha.

## 📁 Estrutura do Projeto

* `index.html` — Contém a estrutura e o conteúdo textual da página.
* `style.css` — Arquivo de estilos responsável por deixar o layout bonito e responsivo.
* `script.js` — Lógica do placar interativo em JavaScript.
* `README.md` — Documentação explicativa do projeto.

## 🚀 Como Executar

1. Baixe os 4 arquivos e salve todos na **mesma pasta**.
2. Abra o arquivo `index.html` com dois cliques para abrir o site em qualquer navegador web.
